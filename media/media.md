# Copy Instructions

This drawer should contain the original Curse of Monkey Island files - This is only required when developing for Goodsoup. 

## Curse of Monkey Island - Two CDs.

1. Copy all of the files and folders of `MONKEY3_1:` into `media/cds/MONKEY3_1`
2. Copy all of the files and folders of `MONKEY3_2:` into `media/cds/MONKEY3_2` and skip over any existing files.

## Curse of Monkey Island - DVD

1. Copy all of the files and folders in the DVD into `media/dvd/` 

## Curse of Monkey Island - Digital Release

1. Copy all of the files and folders in the digital release into `media/digital/`
